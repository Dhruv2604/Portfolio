# Dhruv Aryaman — Recruiter Portfolio

A high-tech, responsive personal portfolio built with plain HTML, CSS and JavaScript and ready for Vercel.

## Included
- Large typography and premium dark tech aesthetic
- Animated grid/HUD visuals and pointer glow
- Scroll-reveal animations
- Interactive project filters
- 3D project-card hover interaction
- Separate **Live Demo** and **GitHub** links
- Facial Recognition Delivery Drone section with the two supplied demo videos
- Responsive mobile layout
- No framework, build step, Node.js or backend required

## Important: add your real Vercel URLs
Open `script.js` and replace:
- `YOUR-TRADEOPS-VERCEL-URL`
- `YOUR-ATHLETE-VERCEL-URL`
- `YOUR-LUNG-VERCEL-URL`

The project cards already have separate GitHub links.

## Deploy
1. Push the folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: **Other**.
4. Build command: leave empty.
5. Output directory: leave empty.
6. Deploy.
